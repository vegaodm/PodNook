Getting started

Subscribe to a podcast

  1. Open Library and tap + in the header.
  2. Paste the show's RSS feed URL (for example https://feeds.npr.org/510289/podcast.xml).
  3. Tap Subscribe. PodNook fetches the feed once and stores it locally.

A plain website URL will not work — PodNook needs an RSS or Atom feed address.

Import an OPML export AntennaPod · Overcast · Pocket Casts

  1. Export your subscriptions as OPML from the other podcast app.
  2. Either keep the file anywhere in the Files app, or drop it into Files → On My iPhone → PodNook.
  3. Open PodNook → Settings → Import OPML, then pick the file.
  4. PodNook shows how many shows it found and imports them three at a time. Shows already in your library are skipped; broken feeds are listed at the end.

Refresh

Pull down on the library to refresh everything, or tap the refresh button in the header. PodNook also refreshes on launch and when you return to the app after 15 minutes. Feeds use conditional requests, so unchanged shows cost almost no data.

Playback

  • Background playback — audio keeps playing when you lock the screen or switch apps.
  • Lock screen & Control Center — play/pause, skip back 15 s, skip forward 15 s, previous and next episode.
  • Headphones — unplugging them pauses playback; a phone call pauses and resumes afterwards.
  • Speed — tap the speed chip in the player, or set it in Settings. 0.8× to 2×.
  • Resume — progress is saved every 5 seconds. Episodes under 10 seconds of progress start over.
  • Queue — “Add to Queue” from an episode; playback continues with the next episode automatically.

Downloads

  • Tap the download arrow on an episode. Progress is shown on the row and in Downloads.
  • Downloads resume where they stopped, including after losing the network or restarting the app.
  • Playback prefers the downloaded file, so offline listening needs no network.
  • Cancel an in-flight download from the same row; delete a finished one with the trash button.
  • Settings → Delete All Downloads clears every audio file; Clear Artwork Cache clears images only.

Troubleshooting

SymptomWhat to try
Library shows “Update failed” The show's server did not answer. Pull to refresh later; the badge clears after a successful update.
Download fails with “Link expired” The media URL uses a temporary token. Refresh the feed, then retry the download.
Download stops at a percentage Tap retry; PodNook resumes from the bytes it already has. If the host cannot resume, it starts over.
Episode won't play Check the connection. If the show only offers HTTP media, PodNook allows media loads but some hosts block non-browser clients.
OPML import finds no shows Make sure the file ends in .opml or .xml and contains xmlUrl attributes. Empty folders are ignored.
Black screen with “In iOS 14+, debug mode Flutter apps can only be launched from Flutter tooling…” That build was a Debug build launched from the home screen. Launch it from Xcode or flutter run, or install a Release build.
No lock-screen controls Start an episode once inside the app; the now-playing info is published with the first play.
Covers are missing Some CDNs block direct image requests. A placeholder is shown and playback is unaffected.

FAQ

Does PodNook collect any data?

No. No account, no tracking, no ads, no analytics SDK. See the privacy policy.

Does it sync across devices?

Not in 1.0. Everything is local; there is no server and no iCloud sync.

Is there CarPlay, a sleep timer or chapter support?

Not in 1.0. Lock screen and Control Center controls are supported. CarPlay, sleep timer and chapters are planned for later versions.

Can I export my subscriptions?

Not yet. Import works; export is on the roadmap.

How much space do downloads use?

Settings shows the total. A one-hour episode is typically 30–60 MB depending on the publisher's bitrate.

What happens if I delete the app?

Your subscriptions, progress and downloads are removed with it. Nothing is stored elsewhere.

快速开始

订阅播客

  1. 打开 Library，点右上角 +。
  2. 粘贴节目的 RSS 地址（例如 https://feeds.npr.org/510289/podcast.xml）。
  3. 点 Subscribe。PodNook 抓取一次 feed 并保存在本地。

普通网站地址不行，必须是 RSS/Atom 的 feed 地址。

导入 OPML AntennaPod · Overcast · Pocket Casts

  1. 在原来的播客 App 中把订阅导出为 OPML。
  2. 文件可以放在“文件”App 的任意位置，或放进 文件 → 我的 iPhone → PodNook 文件夹。
  3. 打开 PodNook → Settings → Import OPML，选择文件。
  4. PodNook 会显示解析到的节目数量，并以 3 个并发导入。已在库中的会跳过， 失败的 feed 会列在结果里。

刷新

在库页面下拉即可刷新全部，或点右上角刷新按钮。App 启动时、以及离开 15 分钟后回到前台也会自动刷新。 使用条件请求，未更新的 feed 几乎不消耗流量。

播放

  • 后台播放：锁屏或切换 App 时音频继续。
  • 锁屏 / 控制中心：播放暂停、后退 15 秒、前进 15 秒、上一集、下一集。
  • 耳机：拔掉耳机自动暂停；来电时暂停，结束后恢复。
  • 倍速：点播放页的倍速胶囊，或在设置里改，0.8×–2×。
  • 续播：进度每 5 秒保存一次；不足 10 秒的进度视为从头开始。
  • 队列：单集里点“加入队列”，播完自动接下一集。

下载

  • 点单集右侧的下载箭头，进度会显示在列表和 Downloads 页。
  • 支持断点续传：断网或重启 App 后会从已下载的位置继续。
  • 播放优先使用已下载文件，离线也能听。
  • 同一行可以取消下载；已完成的用垃圾桶按钮删除。
  • Settings → Delete All Downloads 清空全部音频； Clear Artwork Cache 只清封面。

疑难排查

现象可以尝试
库中显示 “Update failed” 节目服务器没有响应。稍后下拉刷新；成功更新后标记会自动消失。
下载失败，提示 “Link expired” 音频地址使用了临时令牌。先刷新 feed，再重试下载。
下载卡在某个百分比 点重试，PodNook 会从已有字节续传；若对方不支持续传则从头下载。
单集无法播放 先确认网络。若节目只提供 HTTP 音频，PodNook 允许媒体加载，但部分服务器会拒绝非浏览器客户端。
OPML 导入找不到节目 确认文件后缀是 .opml 或 .xml，且其中包含 xmlUrl 属性；空文件夹会被忽略。
黑屏并提示 “In iOS 14+, debug mode Flutter apps can only be launched from Flutter tooling…” 那是从桌面启动的 Debug 包。请用 Xcode 或 flutter run 启动，或安装 Release 包。
锁屏没有控制按钮 先在 App 内播放一次，Now Playing 信息才会发布到系统。
封面不显示 部分 CDN 会拦截直连图片请求，此时显示占位图，不影响播放。

常见问题

PodNook 会收集数据吗？

不会。没有账号、没有追踪、没有广告、没有统计 SDK。详见 隐私政策。

支持多设备同步吗？

1.0 不支持。所有数据都在本机，没有服务器，也没有 iCloud 同步。

有 CarPlay、睡眠定时、章节吗？

1.0 没有。已支持锁屏与控制中心控制；CarPlay、睡眠定时与章节在后续版本规划中。

可以导出订阅吗？

暂时只能导入，导出在后续计划中。

下载会占多少空间？

设置页会显示总占用。一小时的单集通常 30–60 MB，取决于发布方的码率。

删除 App 会怎样？

订阅、进度和下载文件都会随之删除，不保留任何副本。
